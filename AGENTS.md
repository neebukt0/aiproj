# AGENTS.md — OpenCode Agent Config

## Проект
Финальный проект СРС «AI Driven Development» — вариант №3 «Мероприятия».
Веб-приложение с бронированием мероприятий в зале (React + Django REST + MySQL).

## Стек
- Backend: Django + Django REST Framework
- Frontend: React
- База: MySQL
- Auth: JWT (SimpleJWT, access 15 мин / refresh 7 дней, blacklist)

## Документация проекта
- `docs/SPEC.md` — полное техническое задание/спецификация (обязательно читать перед задачами)
- `docs/PLAN.md` — разбивка на недельные задачи
- `docs/AI_LOG.md` — журнал ИИ-агента (обязателен к заполнению)
- `docs/AI_REVIEW.md` — результаты аудита безопасности
- `docs/prompts/` — история промптов сессий

## Правила работы с агентом
- Задачи — маленькие, выполнять за один заход агента.
- Контекст под контролем: не включать в задачи лишние файлы.
- После каждой значимой задачи — коммит в git.
- Перед коммитом проверять историю на ключи/пароли.
- Не удалять неудачные промпты — они часть истории.
