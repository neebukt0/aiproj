# 2026-11-16 — Сохранение smoke-теста и закрытие недочётов

## Запрос пользователя
> сохрани и исправь недочеты

## Контекст
Перед сессией все 11 файлов истории промптов сверены с проектом. Отсутствующих
файлов и нереализованных функций не найдено. Расхождения были только в
исторических цифрах (17/19/22/28/42/50 тестов, 5/7/8 промптов, 8 скриншотов) и
в одном неоформленном артефакте: сквозной smoke-тест из промпта №7 выполнялся
разово и не был сохранён в `backend/scripts/`.

## Что сделано
- Добавлен `backend/scripts/smoke_check.py` — воспроизводимый сквозной smoke-тест
  на живом сервере (httpx, без прямого доступа к MongoDB). 37 проверок:
  - health и авторизация: вход всех трёх ролей, `/me`, невалидный токен → 401;
  - каталог: размер страницы, всего 20 объектов seed, фильтр по типу,
    регистронезависимый поиск, символы regex → 200, карточка объекта и 404;
  - занятость: `GET /api/resources/{id}/availability` для занятого дня;
  - бронирование: создание, повторная бронь → 409, запрос без токена → 401,
    «мои брони», запрет подтверждения клиентом → 403;
  - статусы: подтверждение сотрудником, `held_until == end_at`, отображение
    подтверждённой брони в занятости, недопустимый переход → 409,
    отмена клиентом и освобождение слота;
  - панель и журнал: брони на день, запрет клиенту → 403, логи брони и общий
    журнал;
  - отчёты: агрегация, запрет клиенту → 403, CSV с `text/csv` и заголовком;
  - админ: список пользователей, создание сотрудника, деактивация, удаление
    и невозможность входа после удаления;
  - refresh/logout/blacklist: новый access, logout, повторный refresh → 401.
- Скрипт оформлен в стиле `refresh_check.py` и `concurrency_check.py`: argparse,
  async httpx, чек-хелпер, итог `RESULT: OK` / `RESULT: FAILED`.
- Прогон на живом mock backend: **37 проверок, 0 ошибок** → `RESULT: OK`.
- Добавлен данный файл истории промптов (12-й).
- Обновлены `README.md`, `docs/AI_LOG.md`, `docs/AI_REVIEW.md` и Word-отчёт:
  команда запуска smoke-теста, актуальное число файлов промптов (12) и
  упоминание воспроизводимого скрипта вместо разового прогона.

## Проверки
